# TELEMETRY-CONTRIBUTIONS 验收报告（中文）：Live 模式的遥测特征贡献

## 1. 任务概要

- **来源**：用户 10-22 发现 Explanation 视图里 Telemetry Evidence 卡片的「Feature Contribution」一直显示 unavailable。
- **根因**：迁移到真实 XGBoost 后，Live 用的 `TrainedProvider` 从来没有填写 `telemetry_feature_contributions`，这个字段一直是空列表。旧 replay 模式里看到的数字，是 FYP1 时手写在表里的。
- **用户裁定（方案 A）**：解释**非安全风险** `1 − P(Safe)`，也就是送进融合的那个数。
- **实现了什么**：
  - 用 XGBoost 自带的 TreeSHAP，在与概率预测相同的树上计算，取 Safe 类贡献的相反数，正号表示推向不安全；
  - provenance 记下计算方法和基线，满足 Σ 贡献 + 基线 = −Safe 打分；
  - R10 REPEAT 沿用第一次登记时的贡献；
  - 卡片按绝对值显示前 3 个特征，并标注「非安全风险、正号推向不安全、TreeSHAP、log-odds、不代表因果」；旧 replay 的记录不加这条标注。
